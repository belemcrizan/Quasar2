# QUASAR2 v0.2 — regime experiment (loop frozen)

**Status:** implemented harness, evidence not yet paper-grade  
**Treatment:** QUASAR2 v0.1.1 inference loop, unchanged  
**Date:** 2026-08-25

> Under what query-uncertainty regimes does maintaining competing intent
> hypotheses and acquiring discriminative evidence improve autonomous answer
> correctness relative to the *same* single-shot retriever?

This is a **hypothesis of regime**, not a claim that hypothesis-driven retrieval
is generally better than BM25.

\[
\Delta_{loop}(R,Q)
=
\mathrm{Metric}(\mathrm{QUASAR2}(R), Q)
-
\mathrm{Metric}(R, Q)
\]

The astronomy/AI 80-document set is the **sanity / CI mechanism test**.
It is not the primary scientific benchmark.

## What v0.2 changes

| Change | Why |
| --- | --- |
| Isolated ops runbook fixture | Shared symptom language; relevant docs do not copy the query |
| Factorial cells \(Q=(A,L,P,U,D)\) | Sampled design, not a 4⁵ Cartesian product |
| Matched backends \(R\) vs QUASAR2\((R)\) | Isolates the loop from the retriever |
| Ranking vs evidence vs interpretation | Recall@k and ARR can disagree |
| Crossover table by severity | The plot that would justify Adaptive QUASAR |
| Hashing dense = debug; neural = optional extra | Paper-grade dense is plug-in, not the loop |

What v0.2 **does not** change: belief update, decision utilities, ASK/EXPLORE
gates, candidate cap, Mode A catalog generator.

What v0.2 **does not** implement: \(H_{unknown}\), DEFER, MCTS, RL, receding
horizon, LLM HyDE. Those belong to [deferred v0.3](V0.2_EXPERIMENT_PROTOCOL.md)
after \(\exists Q:\Delta_{loop}(Q)>0\) is answered.

## Real case

The bundled scientific fixture is **on-call incident retrieval**: a noisy
symptom query against overlapping runbooks (secret skew vs TLS vs DNS vs pool
exhaustion, and so on). That is a realistic internal-search problem.

It is still small. External collections (BEIR, private KBs) load as JSONL
through the same `Retriever` interface. Drop files under `data/external/` and
point `paths.corpus` at them.

## Commands

```bash
quasar2 materialize-ops
quasar2 validate --config configs/poc.yaml          # sanity corpus
quasar2 benchmark --config configs/poc.yaml         # CI mechanism test
quasar2 experiment --config configs/v02_regime.yaml # regime evidence
```

Smoke:

```bash
quasar2 experiment --methods bm25,full+bm25 --seeds 42 --limit 3
```

Optional neural backend (downloads weights):

```bash
python -m pip install -e ".[neural]"
quasar2 experiment --methods neural,full+hybrid --limit 3
```

`full+neural` is valid once `retrieval.backend` / factory knows `neural`.
Add `full+neural` to `experiment.methods` only after `quasar2[neural]` is installed.

## Falsification

- If \(\Delta_{loop}\) is ≤ 0 in every severity bin after cost, the loop is
  not justified on that fixture.
- If ranking R@10 falls while IRR rises, report the trade-off; do not tune
  until ranking wins.
- Do not fit an adaptive threshold \(\tau\) on the same run that discovered
  the crossover.

## Seeds

The bundled config uses three seeds for local iteration. A paper-grade claim
requires the preregistered seed count (30+ when the method is stochastic) and
an external corpus.
